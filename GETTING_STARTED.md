# Getting started

- **Using Muninn:** download the release zip and read
  README_BINARIES.txt in it (`packaging/README_BINARIES.txt` here): what's in it,
  what your program must match (MSVC, Release /MD, C++17), and the CUDA 13 and
  cuDNN 9 DLLs a GPU run needs. [README.md](README.md) has a short example of
  each API; the guides are in [docs/](docs/).
- **Building Muninn:** see [SETUP.md](SETUP.md).
